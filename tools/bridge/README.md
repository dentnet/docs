DENT Bride is a convenient tool designed to facilitate the seamless transfer of DENT tokens and DENTX from the Ethereum network to DENTNet and, if needed, back.

To move DENTs from Ethereum to DENTNet, follow [move-dents-from-ethereum-to-dentnet.md](move-dents-from-ethereum-to-dentnet.md "mention")

To move DENTX from Ethereum to DENTNet, follow [move-dentx-from-ethereum-to-dentnet.md](move-dentx-from-ethereum-to-dentnet.md "mention")
