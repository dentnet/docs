# Wallets

DENTNet supports several ways to create a wallet. Please pick a wallet app based on your security needs. Please find here a list of supported wallets:

* [Polkadot Ledger App](polkadot-ledger-app.md) - the official Polkadot Ledger app is compatible with DENTNet
* [SubWallet](subwallet.md) - a wallet for iOS and Android and has a Chrome Extension and Web Dashboard
* [Nova Wallet](http://novawallet.io) - a wallet for iOS and Android
* [PolkadotJS](polkadotjs.md) - extension similar to Metamask
* [Vault App](vault-app.md) - an (offline) mobile app for iOS and Android to create and manage secure non-custodial wallets
