# Why DENTNet

Every country worldwide has mobile operators that provide access to the Internet and other services. Operators have software, hardware, and employees to handle tasks like subscription management, accounting, or invoicing.&#x20;

In every country, mobile data is the same and subscriptions work the same way. But each operator is running and paying for its infrastructure to solve the same tasks.

This is a lot of duplicated infrastructure and can be done much more efficiently with blockchain technology.

DENTNet is designed to offer one global infrastructure for managing telecommunication assets such as mobile data or frequencies.

With functions to buy and sell telecommunication assets, automatic accounting, eSIM handling, and many more, DENTNet started as the future operating system for modern mobile operators.
