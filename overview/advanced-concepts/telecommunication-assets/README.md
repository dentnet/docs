# Telecommunication Assets

### General

DENTNet can handle different types of telecommunication assets. Telecommunication assets have characteristics like an expiry date, parameters like country coverage, or quality of service (5G, LTE, 3G).

DENTNet is built to handle these characteristics and provide a scalable solution for issuing, trading, and using these assets.&#x20;

The goal is to include the complete telco stack from issuing an eSIM, buying and selling all kinds of telco assets, and subscriptions, to support tasks like refund management into DENTNet.

### Asset Issuance

To issue an asset, the operator account can call the DENTNet API. A security deposit in DENTX for each created asset is needed.
